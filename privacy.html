Studio Mail privacy policy

Studio Mail is a private tool used only by its owner, on the owner's own computer, with the owner's own Google accounts.

What it accesses

With the owner's consent it reads Gmail messages and Google Calendar events (read-only scopes).

How the data is used

Data is processed and stored only on the owner's own computer, to summarise, search and organise the owner's mail and calendar. It is not sold, shared with other people or companies, used for advertising, or used to train generalised AI models.

Retention and removal

Stored data is deleted automatically after a set retention period. The owner can revoke access at any time at myaccount.google.com/permissions and delete the stored data.

Studio Mail's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
